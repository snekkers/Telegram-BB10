# Вложения и голосовые — 0.6.0

Сохранение между запусками и очистка описаны в [разделе надёжности](reliability.md).

Общий `TelegramStore` формирует `inputMessageDocument`, `inputMessagePhoto` и
`inputMessageVoiceNote` по схеме закреплённой TDLib
`4c6377aa7386c39217878a9a56d581922ad37ca4`. Файлы передаются через
вложенные `inputDocument`, `inputPhoto`, `inputVoiceNote` и `inputFileLocal`.
Права на документы, фото и голосовые проверяются отдельно. Платная отправка
не включается, секретные чаты и темы пока исключены.

## На Mac

В [локальном стенде](macos-diagnostic.md) выберите чат, нажмите
«Прикрепить файл», укажите способ отправки и при необходимости добавьте подпись.
Сам выбор файла ничего не отправляет. Нажмите «Отправить» после предпросмотра.
«Убрать» отменяет выбор. Подпись ограничена 1024 символами.

«Записать голос» запрашивает микрофон только по нажатию. Поддерживаются браузеры,
чей MediaRecorder записывает AAC в MP4/M4A либо одноканальный Ogg Opus.
Повторное нажатие завершает запись; через пять минут она завершается сама.
Запись можно прослушать, убрать или отправить. В браузере без подходящего
кодека можно прикрепить готовый M4A, MP3 или одноканальный Ogg Opus и выбрать
«Голосовое». Длительность готового файла определяется проигрывателем.
WebM автоматически не конвертируется и как голосовое не принимается.

Для входящих голосовых и аудио доступны загрузка и встроенный проигрыватель.
Браузер получает весь файл с локального сервера в Blob, поэтому перемотка
происходит локально. Автоматического воспроизведения нет.

## На BB10

В меню переписки добавлены «Прикрепить файл», «Отправить фото» и
«Записать голос». Нативный FilePicker выбирает исходник; приложение делает
собственную копию перед отправкой. AudioRecorder пишет моно M4A; нажатие
«Завершить запись» готовит файл для предпросмотра и отдельной отправки.
Для записи нужен `record_audio`, для выбранных общих файлов — `access_shared`.
Готовое вложение открывается системным обработчиком как копия только для чтения.
При уходе из чата запись отменяется; выбор и отправка проверяют текущий чат.

**Это скомпилировано для ARMv7 и x86. FilePicker, микрофон, M4A-файл,
системный проигрыватель и раскладка на Classic ещё не проверены.**
Готовые аудиофайлы на BB10 пока отправляются как документы; отдельное голосовое
создаётся встроенной записью. На Mac готовые голосовые поддерживаются.

## Ограничения и хранение

- Документ — до 50 МиБ; фото JPEG/PNG — до 10 МиБ. Размеры фото считываются из
  файла: сумма ширины и высоты до 10000, отношение сторон не более 20.
- Голосовое — до пяти минут и до 50 МиБ. Выполняется проверка сигнатуры контейнера;
  это не полная проверка декодирования. Окончательный формат проверяет TDLib/Telegram.
- Отправляется только файл из закрытого `uploads` внутри каталога данных.
  HTTP-загрузка требует ключ, правильные Host/Origin и ID открытого чата.
  Имя очищается, сервер возвращает случайный ID вместо возможности указать путь.
  Общий код отклоняет символьный файл-ссылку и выход за каталог `uploads`.
- Копии имеют права 0600, каталоги — 0700. Они не получают дополнительного
  шифрования. Локальный сервер отдаёт известные вложения текущего чата только
  из `files` и `uploads`, проверяя путь заново.
- После передачи запроса копия сохраняется: TDLib ещё может читать её для
  загрузки. Подтверждённые копии старше суток автоматически очищаются, если
  их не использует незавершённая попытка. Лимит — 32 файла / 256 МиБ на Mac;
  на BB10 — 32 файла с резервом под следующую копию до 50 МиБ.
  Неопределённые попытки и неизвестные файлы требуют ручной проверки.
  Не удаляйте входные файлы во время отправки.
- При явном отказе последнее вложение чата и подпись доступны для ручного
  восстановления. Выбор вложения, подпись и сведения об отправке сохраняются
  между запусками в закрытом журнале. При неизвестном результате показана
  просьба проверить историю перед ручным повтором.
- При неизвестном результате автоматической повторной отправки нет.
  Перед ручным повтором проверьте историю, чтобы избежать дубля.
- Индикатор загрузки использует `updateFile.remote.uploaded_size`.
  Скачивание фото, документов и аудио по-прежнему ограничено 50 МиБ.

## Проверки

QtTest: 45 успешных строк с setup/cleanup (41 содержательный сценарий).
Добавлена проверка документов, голосовых, ограничений, путей, символьных ссылок,
раздельных прав и восстановления при отказе до/после ответа `sendMessage`.

На M1 интеграция HTTP → общий C++ → тестовый процесс проверяет документы,
фото и голосовые, авторизацию загрузки, размер, привязку к чату, отмену и
восстановление. Синтетический M4A из секундного тона загружен в браузере:
предпросмотр и проигрыватель сообщения определили длительность и декодировали файл.
Микрофон для автоматической проверки не использовался. Отдельный тест
`node tests/diagnostic-recording-tests.js` с подставными MediaRecorder/микрофоном
проверяет ожидание разрешения, смену чата с возвратом, остановку дорожек,
отмену таймера, отказ в разрешении и отсутствие отправки при завершении записи.

**Вход в настоящий аккаунт и передача медиа через Telegram ещё не проверены.**
Лимит my.telegram.org не мешает этим локальным тестам, но настоящий сетевой
тест остаётся отдельным этапом.
