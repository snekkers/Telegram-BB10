# Emoji, прочтение чата и непрерывный ввод

При открытии чата после получения первой страницы истории вызывается
`viewMessages` с `messageSourceChatHistory` и `force_read=true`.
Счётчик непрочитанных обновляется подтверждением Telegram
`updateChatReadInbox`. Ошибка загрузки истории не отмечает чат прочитанным.

Поле ввода больше не отключается из-за ожидающей отправки. Можно сразу набирать
следующее сообщение; кнопка отправки продолжает учитывать занятость отправки,
права чата и готовность сеанса. После успешной передачи текста поле очищается
и сохраняет фокус. Исходный текст следующего черновика сохраняется обычным способом.

Текст сообщений и подписи с emoji отображаются штатными Label и ImageView.
Цветные изображения Twemoji 16.0.1 включают оттенки кожи, флаги, keycap и
составные ZWJ emoji (3846 изображений). Ресурсы упакованы в `assets/emoji.rcc`;
исходные PNG и описание ресурса находятся в `resources/`.
Пересборка ресурса: `bash scripts/build-emoji-resources.sh`.
Шрифт BB10 не определяет доступность этих символов. Исходный Unicode остаётся
в сообщении и используется для копирования и ответа. HTML из сообщения не
интерпретируется. Обычные сообщения без emoji используют один штатный Label.
Текст сообщений не записывается во временные изображения.

Источник изображений и лицензия CC BY 4.0 находятся в `assets/licenses/Twemoji-*`.

Проверки: Qt-тесты прочтения трёх чатов при открытии, сохранения черновиков и
разбора одиночных и составных emoji без изменения исходного текста.
Проверка на Classic включает цветные emoji, переносы строк, отправку клавишей
Enter и кнопкой, сохранение фокуса после отправки.
Результаты проверки телефона записываются в `build/emoji/device-checks.json`.
