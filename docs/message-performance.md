# Telegram 0.14.0.19: длительная работа с сообщениями

Исправлены найденные по коду причины задержек:

- Истёкшие запросы отправки больше не занимают активный лимит запросов истории. Сопоставление поздних ответов сохранено, автоматического повтора отправок нет.
- Обновления движка обрабатываются порциями до 64 событий с возвратом управления интерфейсу. Списки чатов и сообщений пересобираются один раз на порцию. Прокрутка и уведомления о входящих выполняются после обновления списка.
- При следовании новым сообщениям список ограничен скользящим окном: после 1000 строк остаётся примерно 800. История доступна для повторной загрузки. Чтение старой переписки, выбор сообщений, ответы и редактирование исключены из этой очистки.
- Метаданные вложений предыдущего чата освобождаются при переключении; метаданные аватаров сохраняются.
- Повторные запросы отметки одного и того же диапазона прочитанным объединяются. Отказ и таймаут позволяют повторить запрос.
- Конец локального кэша после потери сети больше не блокирует продолжение истории при восстановлении подключения.
- Открытая фотография больше не проходит повторное масштабирование на каждом событии чата.

Регрессионные сценарии используют синтетический движок без сети: поток из 600 сообщений, серия из 9000 сообщений с ограничением памяти и сохранением читаемой истории, 64 отправки без ответа с последующей загрузкой другого чата, потеря и восстановление сети. Существующие проверки охватывают поздние ответы, перестановки событий отправки, черновики, вложения, переключение чатов и восстановление после остановки процесса.

Ускоренные проверки не заменяют наблюдение за реальной сетью и сервером в течение часа. Измерение аккумулятора здесь не выполняется.
